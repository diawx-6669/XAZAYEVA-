# Абляция: награда без требования доказательств

Сгенерировано `make ablation` (`tools/ablation_evidence.py`): 120 свежих эпизодов (seed 780000+). Те же ответы
оценены настоящим оценщиком дважды: как есть и с отключённой проверкой набора доказательств (подмена
`matcher.satisfied_set` только в процессе инструмента; файлы ядра не меняются).

| Ответ | Возврат с доказательствами | без доказательств | Δ | TP с / без |
|---|---|---|---|---|
| `oracle` | +1.000 | +1.000 | +0.000 | 217 / 217 |
| `simple_reconcile` | +0.207 | +0.207 | +0.000 | 190 / 190 |
| `flag_all` | -1.000 | -0.988 | +0.012 | 0 / 12 |
| `random_explorer` | -0.320 | -0.320 | +0.000 | 0 / 0 |
| `simple_reconcile, evidence stripped` | -0.770 | +0.207 | +0.977 | 0 / 190 |
| `attack:cem_best (no answer key)` | -0.991 | -0.988 | +0.003 | 6 / 8 |
| `attack:evidence_spam` | -1.000 | +0.300 | +1.300 | 0 / 217 |
| `attack:guess_ids` | -1.000 | -1.000 | +0.000 | 0 / 0 |
| `attack:type_bruteforce` | +0.220 | +0.220 | +0.000 | 217 / 217 |

## Вывод

* Больше всего от отмены доказательств выигрывает `attack:evidence_spam` (Δ = +1.300): ответ, который **знает** суммы
  и ID, но ничего не доказывает, получает 217 TP — столько же, сколько oracle (217).
* «Знать ответ — не значит доказать»: `simple_reconcile` без доказательств получает столько же, сколько с ними, только
  если доказательства не требуются; с требованием — 0 TP. Награда учит агента ссылаться на записи.
* Стратегии без доступа к эталону (`attack:cem_best`, `flag_all`, `random_explorer`) почти не выигрывают: их
  сдерживают тип, ID и сумма. Доказательства закрывают именно путь «узнал ответ в обход инструментов».
