# Человек против агента: протокол базовой линии

Человек проходит эпизод **через ту же среду**, что и агент: 5 инструментов, 100 шагов, каждая
команда среды (даже ошибочная) тратит шаг, тот же оценщик и та же награда. Команда:
`python -m auditenv play` (код: `auditenv/play.py`, тесты: `tests/test_play.py`).

Отличия от агента — ровно два, и оба записываются в первую строку траектории (`protocol`):

| | Агент | Человек | Почему |
|---|---|---|---|
| Лимит времени | 60 с | 30 мин (`--time-limit 1800`) | человек читает медленнее программы |
| Черновик выводов (`flag`, `draft`, `drop`) | — | 0 шагов | это заметки на бумаге, а не действие в среде |

## Правила, чтобы результат был честным

1. **Только свежие эпизоды.** Играйте с `--seed`: эпизод генерируется в памяти, эталон на диск не
   пишется, подсмотреть его нельзя. Открытые эпизоды из `episodes/` для замера не годятся: команда
   их видела, а рядом лежит `grader/`.
2. Seed выбирает не игрок. Список seed ниже зафиксирован заранее.
3. Можно бумагу и калькулятор в среде (`calc`). Нельзя: код, другие окна с данными эпизода,
   подсказки других людей.
4. Результат пишется всегда, в том числе неудачный: `--summary reports/human_baseline.jsonl`.

## Команды

```bash
python -m auditenv play --seed 31337 --config train-easy --player ibra --summary reports/human_baseline.jsonl --out reports/human_traj_ibra.jsonl
```

Внутри: `help` — список команд. Типичный ход аудитора: `get policy` → `ls invoices` →
`ls payments` → `ls ledger` (и `ls ledger next`) → `doc ...` по подозрительным → `flag ...` → `draft` → `submit`.

Пример вывода в черновик (сумма в минимальных единицах базовой валюты, ID и доказательства через запятую):

```
flag duplicate_invoice SF-QJKZB9P 125000 DC-FQD2FTX2,DC-TJDA8MTQ,LR-AAAA,LR-BBBB повтор счёта
```

## Таблица результатов

Заполняется из `reports/human_baseline.jsonl` (одна строка на эпизод; поля: player, episode_id,
steps, wall_s, tp, fp, fn, f1, reward, truncated). Для сравнения — те же seed для политик:
`python -m auditenv run --policy simple_reconcile --seed 41001 --config dev-mixed`.

| Кто | Эпизодов | F1 средн. | Награда средн. | Шагов средн. | Время средн. |
|---|---|---|---|---|---|
| Ибрагим | | | | | |
| Алдик | | | | | |
| `simple_reconcile` | | | | | 0.1 с |
| `random_explorer` | | | | | 0.1 с |

Что ожидаем увидеть (записано до замера): человек находит `duplicate_invoice` и `period_cutoff`
почти так же хорошо, как скрипт, но проигрывает на `fx_rate` (пересчёт по курсу вручную долгий) и
тратит больше шагов. Если окажется наоборот — это тоже результат, его записываем как есть.
