# Раунд 4: свои идеи (часть 2)

Записано **до** реализации, 22.11 ночью (время Астаны). Правила те же, что для части 1: ядро
(`auditenv/generator/`, `env/`, `grader/`, `runner.py`, `schemas/`, `configs/`) не трогаем; каждая
идея — отдельный коммит; после каждой `make quick`; тяжёлое — в отдельные make‑цели; `make check`
≤ 2 минут. Сверено с `docs/`, `reports/`, `Makefile` и `git log`: ниже нет повторов уже сделанного.

Сортировка — по «польза для раздела 10 кейса / убедительность для жюри» к «риску сломать
сдачу». Колонка «Статус» заполняется по мере работы; итог — в финальном отчёте раунда.
